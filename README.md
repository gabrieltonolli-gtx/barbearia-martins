# Barbearia Martins — site institucional

Site estático da Barbearia Martins (Av. Shishima Hifumi, 2204 · Urbanova, São José dos Campos).

- Abra `index.html` no navegador; não precisa de servidor nem de build.
- Animações: GSAP + ScrollTrigger e Motion (arquivos locais em `assets/vendor`).
- Agendamento pelo Booksy; mapa interativo do Google Maps.
- Créditos e licenças das fotos em `creditos.html`.
